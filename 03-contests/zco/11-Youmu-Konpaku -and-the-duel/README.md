# Youmu Konpaku and the Duel

This folder contains two attempts for a health/damage optimization problem.
The exact statement and constraints are needed to verify the damage formula
and whether each attempt is fast enough.

- `solution.cpp` uses a direct search over move counts.
- `solution-02.cpp` searches the minimum attack count for each charge count.

Treat both as practice attempts until checked against the original statement
and test cases.
