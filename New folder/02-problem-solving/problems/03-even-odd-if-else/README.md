# Even or Odd

## Task

Read an integer `N`. Print whether it is even or odd.

## Rule

An integer is even when its remainder after division by `2` is zero:

```cpp
N % 2 == 0
```

## Examples

```text
Input: 8
Output: even
```

```text
Input: 7
Output: odd
```

## Important

Use the exact output words required by the judge. The current program prints
sentences, so replace those sentences if the original problem expects only
`EVEN` or `ODD`.
