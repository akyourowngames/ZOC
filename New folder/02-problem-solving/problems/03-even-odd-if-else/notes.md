# Learning Notes

## Pattern

```cpp
if (n % 2 == 0) {
    // even
} else {
    // odd
}
```

This is the basic two-branch `if`/`else` pattern.

## Complexity

The check takes `O(1)` time and `O(1)` memory.

## Review question

Why does checking `n % 2 == 0` work for every even integer, including zero?
