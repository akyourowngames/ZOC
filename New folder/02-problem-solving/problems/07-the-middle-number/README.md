# The Middle Number

## Task

Read three integers `A`, `B`, and `C`. Print the value that is neither the
largest nor the smallest.

## Example

```text
Input: 9 2 6
Output: 6
```

## Assumption

The current solution is written for three distinct values. If equal values
are allowed, the problem must define what "middle" means. Do not silently
assume a tie rule.
