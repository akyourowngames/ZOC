# Learning Notes

## Useful pattern

```cpp
lastDigit = number % 10;
lastTwoDigits = number % 100;
```

The divisor tells you how many decimal positions remain.

## Beginner checklist

- Use integer variables for integer input.
- Do not use `/` when you need the remainder.
- Match the required number of output lines exactly.
- Test `0`, a one-digit number, and a number ending in zero.
