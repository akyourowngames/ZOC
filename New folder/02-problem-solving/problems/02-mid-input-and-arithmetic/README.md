# Last Digits and Remainders

## Task

Read an integer `num` and print:

1. `num % 10`
2. `num % 100`
3. `num % 1000`

Print one answer per line.

## Example

```text
Input:
12345

Output:
5
45
345
```

## What to learn

The `%` operator gives the remainder after integer division. It is useful for
last digits, divisibility, odd/even checks, and cyclic patterns.
