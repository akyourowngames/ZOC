# Check Whether a Number Contains Zero

## Current task

Read an integer `N` and print `YES` if at least one of its digits is `0`.
Otherwise print `NO`.

## Examples

```text
Input: 4027
Output: YES
```

```text
Input: 5831
Output: NO
```

## Important

The current active code checks whether zero occurs. It does **not** count how
many times a chosen digit occurs. An older commented section contains the
start of a digit-counting solution.
