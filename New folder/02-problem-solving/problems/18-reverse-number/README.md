# Number Palindrome Check

## Task

Read a positive integer `N`, reverse its digits, and check whether the
reversed number is equal to the original. Print `YES` if it is and `NO`
otherwise.

## Examples

```text
Input: 1221
Output: YES
```

```text
Input: 1234
Output: NO
```

## Important

Despite the folder name, the current program checks for a palindrome; it does
not print the reversed number.
