# Greater of Two Numbers

## Task

Read two integers `A` and `B`, then print the greater value.

## Examples

```text
Input: 8 13
Output: 13
```

```text
Input: -4 -9
Output: -4
```

## Tie rule

If `A` and `B` can be equal, the answer is the same either way. Make sure
your code still prints exactly one number.
