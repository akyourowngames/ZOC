# Count Even Numbers up to N

## Task

Read `N` and count how many even positive integers are in the range from `1`
through `N`.

## Examples

```text
Input: 10
Output: 5
```

The even numbers are `2, 4, 6, 8, 10`.

```text
Input: 7
Output: 3
```

## Solution

See [`solution.cpp`](./solution.cpp).

## Complexity

The current loop uses `O(N)` time and `O(1)` extra space.
