# Learning Notes

## Remainder pattern

`N % 10` gives the last digit, `N % 100` gives the last two, and so on.
The divisor controls how many positions can remain.

## Complexity

If `K` is used to build the power, the simple loop takes `O(K)` time and
`O(1)` extra space.

## Review checklist

- Does the program use `K`?
- Is `K` valid for the chosen type?
- Does the problem want a number or a fixed-width string?
