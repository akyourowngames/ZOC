# Basic Input and Arithmetic

## Topics

Input/output, arithmetic, integer types, overflow, and competitive-programming output.

## Problems

### 1. Double the number

Read an integer `n`, multiply it by `2`, and print the result.

Example:

```text
Input: 7
Output: 14
```

### 2. Rectangle area

Read `length` and `width`, then print `length * width`.

Example:

```text
Input: 5 4
Output: 20
```

### 3. Large product

Read two integers `a` and `b`, where each can be as large as `1,000,000`.
Print `a * b`.

Example:

```text
Input: 1000000 1000000
Output: 1000000000000
```
