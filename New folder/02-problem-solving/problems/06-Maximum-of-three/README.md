# Maximum of Three Numbers

## Task

Read three integers `A`, `B`, and `C`. Print the largest value.

## Examples

```text
Input: 4 11 7
Output: 11
```

```text
Input: -3 -8 -5
Output: -3
```

## Tie cases

If equal values are allowed, the solution must still print that value. A
solution that only checks strict `>` conditions can mishandle some ties.
