# Problem Solving

Create one numbered folder per topic or problem set:

```text
01-basic-input-and-arithmetic/
02-conditionals/
03-loops/
```

Each folder should contain:

- `README.md` - statement, examples, constraints, and checklist
- `idea.md` - hints and thinking steps, without immediately giving everything away
- `notes.md` - lessons, traps, edge cases, and mistakes to avoid
- a `.cpp` source file - clean competitive-programming solution

Keep generated `.exe`, `.obj`, `.pdb`, and `.ilk` files in
`99-build-artifacts/problem-solving/`, never beside the source code.
